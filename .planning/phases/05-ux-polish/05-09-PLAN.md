Relevant prior memory: NotificationsManager `_activeOperations` counter (commit f8917ee) tracks in-flight ops. Each immediate `.sync` increments; each debounced `.idle`/`.error` decrements. Idle is suppressed while counter > 0. Known issue: counter can leak if a `.sync` increments but the corresponding terminal call is lost (extension crash, missed notification, debounce cancellation).

The fix-in-place approach for Gap 16 is **Option 2 (remove the Manage button)** — gear menu already has Disconnect, View in Finder, View in Web Console, Refresh, Reset Sync, Empty Trash, Pause, Copy S3 Path. Manage is redundant.
