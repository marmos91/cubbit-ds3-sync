<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MSI custom action → PowerShell elevated context | Custom actions run elevated during install; PowerShell execution policy bypassed |
| Run key registration → user hive | App auto-launches on user login |
| Authenticode signature → SmartScreen | Unsigned MSI triggers SmartScreen warning; signed MSI builds reputation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
