<objective>
Light up the Windows system tray — the user's persistent surface for sync status, drive management, and quick actions — matching the macOS menu bar tray IA verbatim per CONTEXT D-22 + UI-SPEC §"Component Inventory" tray rows + PATTERNS §2.14.

Purpose: Up to this point the user has a window-based experience (Login, Wizard, DrivesList). The tray is the at-rest surface where sync status is monitored once the windows are closed. WIN-07 specifically requires "tray icon shows idle/syncing/error states"; without this plan the user has no continuous status indication.

Output: A H.NotifyIcon.WinUI TaskbarIcon in the system tray with the four icon states; an Acrylic flyout window showing per-drive rows (StatusPill, TransferSpeedLabel, pause toggle, gear menu, recent files); a SettingsPage with the four sections from UI-SPEC §2.15; and the reusable custom controls (StatusPill, TransferSpeedLabel, TrayDriveRow) that DrivesListPage (Plan 09) can also adopt.
</objective>
