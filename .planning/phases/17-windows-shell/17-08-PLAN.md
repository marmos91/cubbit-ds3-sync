Stand up the WinUI 3 application shell — DI host, design tokens, navigation service, single-instance guard, MainWindow with Mica backdrop — and the first three pages of the user flow (Login, 2FA, Tutorial) with their view-models and authentication service. The 2FA mapping (PATTERNS §2.3, port of LoginViewModel.swift) MUST be byte-identical to Apple per D-15.

Output: An app that launches into the LoginPage with Mica backdrop, accepts credentials, routes 1007 to the TwoFactorPage, and after successful login shows the Tutorial (first run only) — at which point Plan 09 takes over with the drive setup wizard. All copy follows the UI-SPEC Copywriting Contract verbatim.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-entered credentials → AuthenticationService → DS3Session | Plaintext password held briefly in PasswordBox; goes straight into FFI without being persisted |
| TutorialPage → HKCU Run key | App writes to user registry hive |
| App ↔ named Mutex | Single-instance enforcement; another process could attempt to spoof the name |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-08-01 | InfoDisclosure | Password lingering in managed heap after Login | mitigate | PasswordBox.Password copied to local + cleared immediately after `DS3Session.Authenticate`; no field retains it on LoginViewModel; .NET GC limitations documented |
| T-17-08-02 | Spoofing | Single-instance Mutex hijacked by malicious process | mitigate | Mutex name includes user SID suffix (`Cubbit.DS3Drive.SingleInstance.<sid>`) per Task 1; collision requires same-user privilege |
| T-17-08-03 | Tampering | HKCU Run key modified by another app | accept | HKCU is per-user; another app at same privilege can already modify it; D-26 accepts this |
| T-17-08-04 | InfoDisclosure | LoginError text leaking server response | mitigate | MapErrorCopy uses fixed strings from UI-SPEC §Error states; never embeds raw exception messages in user-facing errors |
| T-17-08-05 | Tampering | DS3Session FFI re-entry from button rapid-click | mitigate | LoginViewModel.IsLoading guard prevents double-submit (Test 7) |
| T-17-08-SC | Tampering | Figtree TTF copied from apple/DS3Drive/Assets/Fonts | accept | Assets already in repo, same SHA as Apple-side bundle; no new acquisition |
