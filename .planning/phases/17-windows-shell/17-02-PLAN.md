Create the empty Windows solution skeleton under `windows/` with four projects (App / Sync / Core / Tests), central package management, shared MSBuild properties, and an MSBuild target that invokes cargo and stages `ds3_ffi.dll` into the runtimes folders. The App project needs the .NET 8 target + WindowsAppSDK reference before any XAML can be added. Central package management means later plans simply declare `<PackageReference Include="Foo" />` without versions.

Output: A solution that builds (empty) on Windows after `dotnet restore` + `dotnet build`, with the DLL copy step wired up. App project is sparse-package-ready (Plan 04 adds the manifest). NuGet packages declared per RESEARCH §"Standard Stack" + §"Installation" with versions pinned in `Directory.Packages.props`.
</objective>
