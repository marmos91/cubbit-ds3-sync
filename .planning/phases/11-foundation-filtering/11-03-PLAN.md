<objective>
Route all ListObjectsV2 consumer sites through the centralized `S3KeyFilter.isUserVisible` filter via extension-side `S3Lib` wrappers. This is the single most important regression-prevention task in Phase 11 — it ensures `.thumbnails/` keys never leak into Finder, Files.app, MetadataStore, or SyncEngine.

Purpose: When Phase 13 starts writing `.thumbnails/` objects to S3, every enumeration path will already silently filter them. No `.thumbnails/` folder will ever appear to users.
Output: One new extension-side wrapper file + 8 existing files updated with filter routing.
</objective>

    }
