<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Swift adapter → UniFFI Rust call | Inputs cross the FFI as UTF-8 String / Vec<u8>; panics caught by Phase 15 panic_guard |
| Multipart cancel token → tokio runtime | Atomic flag accessed across multipart loop iterations and Rust crate boundaries |
| reqwest middleware → upstream Cubbit API | Retry policy may amplify intentional 4xx responses (e.g. quota exceeded) |
| Presigned UploadPart URL → external upload | Signed URL contains AWS sigv4 credentials in query string |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-02-01 | Tampering | CancellationHandle Arc<AtomicBool> | mitigate | Use `Ordering::SeqCst` for cancel + load; AtomicBool is lock-free and inherently thread-safe via std::sync::atomic |
| T-16-02-02 | Information Disclosure | upload_from_memory metadata keys | mitigate | Validate metadata keys are ASCII (S3 requires `x-amz-meta-*` keys to be HTTP header-safe). Reject keys containing `\r`, `\n`, control chars. Return DS3Error::S3Error("invalid metadata key") |
| T-16-02-03 | Denial of Service | reqwest-retry on 4xx retried responses | mitigate | Configure `ExponentialBackoff::builder().build_with_max_retries(5)` and only retry transient status codes (5xx, 429, network errors) via `RetryTransientMiddleware` (its default behavior). 4xx are NOT retried. |
| T-16-02-04 | Information Disclosure | presign_upload_part URL leakage | accept | URLs are signed with 5-minute default expiry from caller (Swift adapter enforces ≤604800); scoped to single upload_id + part_number |
| T-16-02-05 | Tampering | Rust panic in new FFI methods | mitigate | All new methods follow existing `runtime().block_on(...)` pattern + Phase 15 panic_guard in `#[uniffi::export]`; any panic → DS3Error::Internal |
| T-16-02-SC | Tampering | New crate installs (reqwest-retry, reqwest-middleware) | mitigate | Both are widely-used (>1M downloads each on crates.io), maintained by TrueLayer / BiomeHQ. Use `cargo install --locked` to pin via Cargo.lock. **Add legitimacy checkpoint before merging Plan 02:** verify `https://crates.io/crates/reqwest-retry` shows recent updates, real maintainer, and no SUS markers. |
</threat_model>
