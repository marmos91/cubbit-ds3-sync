<objective>
Apply **Fix A** from `.planning/debug/phase13-orphan-sweep-deletes-valid.md` per
CONTEXT.md D-01..D-05: `OrphanSweeper.sweep` consults `MetadataStore` as a freshness
backstop before deleting a candidate orphan. The bug is a stale-snapshot race —
`enumeratedKeys` was built when BFS visited the parent prefix; any upload after
that point but before the pass-tail sweep produces a thumbnail that gets
false-positive-deleted. Plan 13-07's upload-hook writes a `SyncedItem` row
synchronously alongside the original PUT, so the MetadataStore lookup sees fresh
uploads even when `enumeratedKeys` does not.

Purpose: Close THUMB-19 conformance regression (orphan sweep correctness). Restores
data integrity for thumbnails of files uploaded during long BFS passes.

Output: Updated `OrphanSweeper`, updated `OrphanSweeping` protocol, updated
`BreadthFirstIndexer` construction site, updated `OrphanSweepTests` with a 7th
test pinning the regression. Single atomic commit per D-17.

    Add `metadataStore: MetadataStore` and `driveId: UUID` stored properties. Update

    Replace line 91 (`if enumeratedKeys.contains(originalKey) { continue }`) with
    the AND-predicate:

    ```swift
    // Implied original still exists in the BFS-enumerated set → keep.
    if enumeratedKeys.contains(originalKey) { continue }

    // Phase 13.1 Finding 4: stale-snapshot backstop (D-01, D-02).
    // The BFS-built `enumeratedKeys` is a snapshot from the moment BFS
    // visited each prefix. Any upload that landed AFTER BFS visited the
    // parent prefix but BEFORE the pass-tail sweep is invisible to that
    // set. Plan 13-07's upload-hook writes a `SyncedItem` row synchronously
    // alongside the original PUT — that row is the freshness backstop.
    // O(1) actor-isolated lookup; no S3 round-trip.
    let hasFreshSyncedItem: Bool
    do {
        hasFreshSyncedItem = try await metadataStore.findItem(
            byKey: originalKey, driveId: driveId
        ) != nil
    } catch {
        // Defensive: on store error, prefer NOT to delete (data-loss-safe default).
        logger.warning(
            "Orphan sweep: MetadataStore lookup failed for \(originalKey, privacy: .public); skipping delete: \(String(describing: error), privacy: .public)"
        )
        continue
    }
    if hasFreshSyncedItem { continue }
    ```

    Note the data-loss-safe default: any MetadataStore error skips deletion (the
    next pass retries; never delete on uncertainty). Use `String(describing: error)`
    not `error.localizedDescription` (per D-06 / Finding 5 pattern, even though this
    is in the orphan-sweep file, not the cascade file).

    ```swift
    /// Seed a SyncedItem in the MetadataStore for an original whose key is

    /// the freshness backstop catches the upload-during-BFS-pass race.
    func testSweepDoesNotDeleteThumbnailWhenSyncedItemExistsForOriginal() async throws {
        let drive = ProviderTestFixtures.makeDrive()
        let prefix = drive.syncAnchor.prefix ?? ""
        let mock = OrphanSweepMockS3Client()

        let freshOriginal = "\(prefix)fresh.png"
        let freshThumb = "\(prefix).thumbnails/fresh.png.jpg"
        mock.listObjectsResults = [.init(
            objects: [makeSummary(key: freshThumb)],
            commonPrefixes: [], nextContinuationToken: nil, isTruncated: false
        )]

        // Seed MetadataStore as if upload-hook wrote the SyncedItem
        // synchronously alongside the original PUT (Plan 13-07).
        let metadataStore = try MetadataStore.makeInMemoryForTests()
        try await metadataStore.batchUpsertItems([
            .init(s3Key: freshOriginal, driveId: drive.id, etag: "etag-fresh", lastModified: Date(),
                  syncStatus: .synced, parentKey: nil, contentType: "image/png", size: 1024)
        ])

        let sweeper = OrphanSweeper(
            s3Client: mock, metadataStore: metadataStore,
            driveId: drive.id, logger: makeLogger()
        )

        // enumeratedKeys is EMPTY — simulates BFS having visited Personal/
        // BEFORE freshOriginal was uploaded. Without the backstop, the
        // sweep would delete freshThumb (Finding 4 symptom).
        let deleted = await sweeper.sweep(
            bucket: drive.syncAnchor.bucket.name,
            drivePrefix: drive.syncAnchor.prefix,
            enumeratedKeys: []
        )

        XCTAssertEqual(deleted, 0, "Fresh thumbnail with SyncedItem must NOT be deleted")
        XCTAssertEqual(mock.deletedKeys, [], "MetadataStore freshness backstop must prevent the delete")
    }
    ```
