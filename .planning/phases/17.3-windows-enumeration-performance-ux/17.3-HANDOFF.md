## Wave 1 — exact next work (start here)

**Bug:** `windows/DS3Drive.Sync/SyncEngine/SyncEngine.cs:121` `PollOnceAsync` lists a single page (`ListObjectsListing(bucket, prefix, "/", null)`), never follows `IsTruncated`/`NextContinuationToken`. `ApplyDeltaAsync` (`SyncEngine.cs:264`) treats locally-known keys absent from the remote map as `Deleted`. So a prefix with >2000 direct children (`LIST_BATCH_SIZE=2000`) prunes everything past page 1 → data loss.

**Fix:** reuse the already-correct full-pagination loop in `PlaceholderMaterializer.ListLevel` (`windows/DS3Drive.Sync/CfApi/PlaceholderMaterializer.cs:71`, chases the token to completion) inside `PollOnceAsync`:
- Replace `SyncEngine.cs:121–148` with a `ListLevel(...)` call; build `remoteMap` from `level.Files` (etag) + `level.Folders` (null etag, preserves the folder-not-pruned semantics at `:145-148`); pass `level.Files` to `ApplyDeltaAsync`.
- Keep `BeginOperation`/`EndOperation(Idle|Error)` bracketing + the `OperationCanceledException` rethrow.
- `IsInternalMarker`/hidden filtering is already inside `ListLevel`.

**Fixture first (Wave 0 leftover):** add `FakePagedSession : IDS3SessionAccess` in `windows/DS3Drive.Tests` returning scripted `DS3ObjectListing` pages with a round-tripping continuation token (page index), honoring page size.

**Tests (Wave 1):**
