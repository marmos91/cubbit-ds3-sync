## Criteria → Evidence

Success criteria (ROADMAP §17.3):
1. Thousands of objects enumerate incrementally (paged), low time-to-first-item, no UI freeze.
2. Placeholder creation/refresh idempotent across repeated enumerations + remote changes — no duplicates, missing, or ghosts.
3. Enumeration + hydration progress observable; bounded concurrency prevents `SlowDown`.

| Criterion / Decision | Behavior | Test Type | Evidence | Status |
|---|---|---|---|---|
| **#1 / D-01** | Poll paginates the FULL remote level before diffing; nothing past page 1 is pruned | Unit (faked paging) + Integration (>2000 keys) | `SyncEnginePollTests.PollOnce_MoreThanOnePage_DoesNotPruneObjectsPastFirstPage` (2500 keys, 2 pages); `EnumerationIntegrationTests.FullEnumeration_ReturnsEveryObject_AcrossPages` | ✅ unit green · 🔶 CI-gated |
| **#1 / D-02** | Placeholders stream per S3 page as pages arrive (root materialize + on-demand fetch), not one buffered batch | Unit (seam recorders) | `PlaceholderStreamingTests.MaterializeAsync_CreatesOncePerPage_AsPagesArrive` ([1,2,3] list-count proof); `FetchPlaceholders_StreamsPerPage_OnlyFinalBatchMarksComplete` | ✅ green · 🔲 Explorer freeze/streaming = manual item 3 |
