# Phase 17.3 Plan 05 (Wave 4): Integration tests, manual smoke, verification & docs

**Closes out the phase's two-layer verification: a credential-gated live-Cubbit suite that seeds a >2000-object prefix and proves full pagination (D-01), idempotent materialization (D-02), on-disk ghost removal with dirty preservation (D-03), and the sync-anchor short-circuit (D-06) end-to-end against real S3; a 12-item cfapi/Explorer manual-smoke checklist for the runtime behaviour that is not headless-testable; and the VALIDATION criteria→evidence contract. STATE + ROADMAP updated to 5/5 plans.**

## Accomplishments
- **`EnumerationIntegrationTests`** (`[Collection("Integration")]`, `IClassFixture<EnumerationIntegrationFixture>`): four `[RequiresCredentials, Trait("Category","Integration")]` tests running the REAL listing/poll code through a `DriveS3SessionAccess` over a minted `DS3DriveS3Client`:
  - `FullEnumeration_ReturnsEveryObject_AcrossPages` (D-01) — `ListLevel` returns all >2000 seeded objects, nothing pruned, no phantom folders.
  - `Materialize_Twice_IsIdempotent_NoDuplicates` (D-02) — two `MaterializeAsync` runs (no-op create) → identical row count.
  - `RemoteDelete_RemovesPlaceholder_PreservesDirtyEdit` (D-03) — poll → remote-delete one clean + one dirty key → poll → clean row + on-disk removed, dirty row preserved, untouched key intact.
  - `Repoll_NoRemoteChange_SkipsApply` (D-06) — poll stores the anchor; a local row deleted out-of-band is NOT restored on an unchanged re-poll (apply skipped).
- **`EnumerationIntegrationFixture`** — authenticates, reconciles a throwaway API key, mints the S3 client, picks the first bucket, and seeds a unique `ds3drive-enum-itest/<guid>/bulk/` prefix with `CUBBIT_TEST_ENUM_COUNT` (default 2050) objects via bounded-concurrency parallel PUTs; deletes all objects + the API key in teardown. No-ops (and every test self-skips) when `CUBBIT_TEST_*` is unset.
- **`windows/manual-smoke-17.3.md`** — 12-item matrix mirroring the D-07/D-33 format: incremental appearance + no freeze at >2000 objects (D-01/D-02), on-demand child population, ghost removal + dirty preservation (D-03), aggregate name-free tray readout (D-04), anchor no-op poll via the `poll unchanged (anchor match)` log line (D-06), bounded listing / no `SlowDown` (D-05), plus pre-flight and sign-off.
- **`17.3-VALIDATION.md`** — maps the 3 success criteria + D-01…D-06 to automated / CI-gated / manual evidence; records the 173/173 headless result.
- **CI:** no change required — `windows-build.yml` already runs the whole `DS3Drive.Tests` assembly on push (new tests included automatically) and the gated `Category=Integration` step on `workflow_dispatch` with `CUBBIT_TEST_*`. `SyncDatabaseTests.MigrationCount` bumped 2→3 for migration 003 (Wave 3).
- Full solution builds 0 warnings / 0 errors; **173/173 non-integration tests pass**; the 4 new integration tests + the existing S3-client integration tests self-skip cleanly (7 skipped) without creds.
