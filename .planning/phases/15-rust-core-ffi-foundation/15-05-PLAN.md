  <behavior>
    compute_diff:
    - Remote has key "a.txt" with etag "1", local empty -> DiffResult.new_or_modified contains "a.txt"
    - Remote has key "a.txt" etag "2", local has "a.txt" etag "1" -> new_or_modified contains "a.txt"
    - Remote has key "a.txt" etag "1", local has "a.txt" etag "1" -> DiffResult is empty
    - Local has key "b.txt", remote does not -> DiffResult.deleted contains "b.txt"
    - Mixed: remote adds "c.txt", modifies "a.txt", local has extra "b.txt" -> new_or_modified = {"c.txt", "a.txt"}, deleted = {"b.txt"}
    - Both empty -> DiffResult.is_empty() is true
    - Keys with None etag: remote None vs local Some -> treated as modified
    - Keys with None etag: remote None vs local None -> treated as identical (no action)

    conflict_key:
    - "folder/file.txt" with hostname "Mac" date 2026-01-15 12:30:45 UTC nonce "ab12" -> "folder/file (Conflict on Mac 2026-01-15 12-30-45 ab12).txt"
    - "file.txt" (no folder) -> "file (Conflict on Mac 2026-01-15 12-30-45 ab12).txt"
    - "folder/.hidden" (hidden file no ext) -> "folder/.hidden (Conflict on Mac 2026-01-15 12-30-45 ab12)"
    - "folder/file" (no extension) -> "folder/file (Conflict on Mac 2026-01-15 12-30-45 ab12)"
    - "a/b/c.tar.gz" (multiple dots) -> "a/b/c.tar (Conflict on Mac 2026-01-15 12-30-45 ab12).gz"
    - Default nonce is 4 chars from UUID
  </behavior>

  <implementation>
    In `tree.rs`: Define TreeSnapshot as a wrapper around `HashMap<String, Option<String>>` where key is S3 key and value is optional ETag. Provide `new()`, `insert()`, `get()`, `keys()`, `len()`, `is_empty()` methods.

    In `diff.rs`: `pub fn compute_diff(local: &TreeSnapshot, remote: &TreeSnapshot) -> DiffResult`. Algorithm: (1) For each key in remote not in local -> add to new_or_modified. (2) For each key in both where etags differ (including None vs Some) -> add to new_or_modified. (3) For each key in local not in remote -> add to deleted. Return DiffResult with the two HashSets.

    In `conflict.rs`: `pub fn conflict_key(original_key: &str, hostname: &str, date: chrono::DateTime<chrono::Utc>, nonce: Option<&str>) -> String`. Generate nonce from `uuid::Uuid::new_v4().to_string()[..4]` if not provided. Format date as `%Y-%m-%d %H-%M-%S`. Split key into parent path and filename. Split filename into name and extension (handle hidden files: if starts with "." and no other ".", treat entire thing as name with no extension). Compose: `"{name} (Conflict on {hostname} {date} {nonce}).{ext}"` or without extension. Prepend parent path if non-empty.

    In `lib.rs`: pub mod diff, conflict, tree. Re-export compute_diff, conflict_key, TreeSnapshot, DiffResult.
