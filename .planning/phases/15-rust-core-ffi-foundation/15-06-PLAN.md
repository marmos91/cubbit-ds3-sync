<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Swift -> Rust FFI | UniFFI-generated Swift calls cross into Rust static library |
| C# -> Rust FFI | P/Invoke calls from .NET cross into Rust DLL via extern "C" |
| Opaque handle | DS3Session pointer passed across FFI boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-14 | Denial of Service | Panic across FFI | mitigate | Every `extern "C"` fn wraps body in `catch_unwind` via `ffi_guard!` macro. UniFFI handles panics automatically on the Swift path. |
| T-15-15 | Tampering | Use-after-free on session handle | mitigate | UniFFI path: Arc reference counting prevents use-after-free. C# path: `ds3_session_destroy` takes ownership via `Box::from_raw`; null check before deref. Document: caller must not use handle after destroy. |
| T-15-16 | Tampering | Double-free on session handle | mitigate | C# path: `ds3_session_destroy` checks for null pointer. After destroy, caller should null out their copy. Document in NativeMethods.g.cs comments. |
| T-15-17 | Information Disclosure | Credential in FFI params | mitigate | Password and secret_key passed as byte slices with explicit length; never stored beyond the scope of the FFI call. zeroize on drop for key material. |
| T-15-18 | Tampering | Invalid UTF-8 from C# | mitigate | All `extern "C"` string params validated via `std::str::from_utf8()` inside ffi_guard; invalid UTF-8 returns error code, never UB. |
| T-15-SC | Tampering | uniffi/csbindgen installs | mitigate | Both [ASSUMED] per audit. uniffi from Mozilla, csbindgen from Cysharp. Build-time only tools generating source code (no runtime risk). |
</threat_model>
