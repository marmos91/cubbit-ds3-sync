<objective>
Delete the BFS thumbnail subsystem. After Wave 2 ships the reactive fallback path, BFS is pure overhead — Apple's `enumerateItems` already drives per-folder listing on demand. Removing BFS removes the single largest LoC source in Phase 13.2's net delta (~570 LoC indexer + hook runner + tests).

Purpose: Realize D-11 + D-22. The hybrid consume path (Plan 02) replaces what BFS did for thumbnails. With BFS gone, the audit findings (Findings 4, 5) lose their root cause — BFS racing the consume + cascade paths.

Output: Three source files deleted (`BreadthFirstIndexer.swift`, `BFSThumbnailHookRunner.swift`, plus the test file). All BFS lifecycle hooks in `FileProviderExtension+Lifecycle.swift` removed. The `breadthFirstIndexer` property + invalidate teardown gone. The `prioritize(prefix:)` callsite in `materializeFolderItem` gone. QueueManager extension gone with parent. Build green; full test suite passes.
</objective>
