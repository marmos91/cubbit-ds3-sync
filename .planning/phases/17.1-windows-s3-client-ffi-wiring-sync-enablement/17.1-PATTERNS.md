## Pattern Assignments

### `ds3_s3_client_new` — Rust FFI export, handle mint (`c_exports.rs`)

**Analog:** `ds3_authenticate` (`core/ds3-ffi/src/c_exports.rs:127-155`). Copy the `ffi_guard!` + `ffi_str`/`ffi_opt_str` + `Box::into_raw` into `*out_handle` shape. **Key divergence:** `DS3S3Client::new` returns `Self` (not `Result`) and does **no** network I/O, so there is NO `runtime().block_on(...)` and the only fallible `?` is the UTF-8 decode.

**Exact mint pattern to copy** (`c_exports.rs:127-155`):
```rust
#[no_mangle]
pub unsafe extern "C" fn ds3_authenticate(
    email: *const u8, email_len: usize,
    /* …more (*const u8, usize) pairs… */
    out_handle: *mut *mut DS3Session,
    out_error: *mut i32,
) -> i32 {
    ffi_guard!(out_error, {
        let email = unsafe { ffi_str(email, email_len)? };
        // …
        let session = runtime().block_on(DS3Session::authenticate(/* … */))?;   // S3: REMOVE block_on
        unsafe { *out_handle = Box::into_raw(Box::new(session)) };
        Ok::<i32, DS3Error>(0)
    })
}
```

**Helpers already present (reuse, do not rebuild):**
- `ffi_str` (`c_exports.rs:35`) — `(*const u8, usize)` → `&str`, `DS3Error::Encoding` on bad UTF-8.
- `ffi_opt_str` (`c_exports.rs:48`) — null ptr OR `len == 0` → `None`. Use this for the `region` param; `DS3S3Client::new` then defaults to `"us-east-1"` (`client.rs:70`). **No special-casing on the C# side: pass `null, 0`.**

**Constructor being exposed** (`core/ds3-s3/src/client.rs:54-79`):
```rust
#[tracing::instrument(skip(access_key, secret_key))]   // secrets already excluded from traces
pub fn new(endpoint: &str, access_key: &str, secret_key: &str, region: Option<&str>) -> Self {
    // builds aws_sdk_s3::Client with force_path_style(true), region.unwrap_or("us-east-1")
}
```

**Target signature** (matches the existing S3 export arg order `s3_handle, then strings`; new mint just emits the handle):
```rust
pub unsafe extern "C" fn ds3_s3_client_new(
    endpoint: *const u8, endpoint_len: usize,
    access_key: *const u8, access_key_len: usize,
    secret_key: *const u8, secret_key_len: usize,
    region: *const u8, region_len: usize,            // null/0 ⇒ None ⇒ "us-east-1"
    out_handle: *mut *mut DS3S3Client, out_error: *mut i32) -> i32
```

### `DS3DriveS3Client.cs` (NEW) — C# handle-owning facade

**Analog:** `windows/DS3Drive.Core/DS3Session.cs` (the whole file is the template). The facade owns exactly one `IntPtr _handle`, mints on construct, frees once on `Dispose`, and short-circuits if the handle is gone. **Divergence (D-01/D-02):** it owns a `DS3S3Client` handle (not a session), and the S3 methods are **moved off** `DS3Session` (`DS3Session.cs:160-298` get deleted/re-homed here) — swapping `EnsureHandle()` (the SESSION handle, the bug) for this facade's own `_handle` guard.

**Mint factory** — model on `DS3Session.Authenticate` (`DS3Session.cs:39-50`) but call the new export:
```csharp
public static unsafe DS3Session Authenticate(string email, string password, string? tenantId, string coordinatorUrl)
{
    IntPtr handle; int rc; int err;
    fixed (byte* e = M.Utf8(email), p = M.Utf8(password), t = M.Utf8(tenantId), c = M.Utf8(coordinatorUrl))
    {
        rc = DS3Native.ds3_authenticate(e, M.Len(email), p, M.Len(password), t, M.Len(tenantId), c, M.Len(coordinatorUrl), out handle, out err);
    }
    return Complete(rc, err, handle);   // rc != 0 ⇒ throw DS3ExceptionFactory.From(err)
}
```
For the S3 facade, region is optional → pass `M.Utf8(region)` / `M.Len(region)` (both yield `null,0` when the string is null/empty, satisfying the Rust `ffi_opt_str → None` default).

**S3 method bodies to copy VERBATIM** from `DS3Session.cs`, swapping `EnsureHandle()` → this facade's `_handle` guard:
- `ListBuckets` (`:164-168`), `ListObjects` (`:171-184`), `HeadObject` (`:187-200`), `DownloadObject` (`:202-219`), `UploadObject` (`:221-239`), `DeleteObject` (`:242-253`), `CopyObject` (`:256-268`), and the folder-marker pair (`:270-298`) if the engine needs them.

**Lifecycle (single-shot dispose) — copy `DS3Session.cs:340-360`:**
```csharp
public void Dispose()
{
    IntPtr prev = Interlocked.Exchange(ref _handle, IntPtr.Zero);
    if (prev != IntPtr.Zero)
    {
        DS3Native.ds3_session_destroy(prev);   // S3: ds3_s3_client_destroy(prev)
    }
}

private IntPtr EnsureHandle()
{
    IntPtr h = _handle;
    if (h == IntPtr.Zero)
    {
        throw new DS3AuthenticationException(AuthFailureReason.LoggedOut, errorCode: 1005);
    }
    return h;
}
```

**Marshalling + output helpers (`M` nested class) — reuse/extract from `DS3Session.cs:388-421`:** `M.Utf8`, `M.Len` (byte-count from us, never caller-supplied — T-17-05-01), `M.TakeString` (frees via `ds3_free_string`), `M.FreeString`, `M.WrapProgress`. Plus the `Check`/`Parse<T>` helpers (`:364-386`). **Recommendation:** extract `M` to a shared internal helper so both facades reuse it, OR copy it (the research notes either is acceptable; copying keeps the diff local).

**Concurrency note (Pitfall 3 — document in the facade):** the handle may be called by ~40 threads concurrently (`FetchDataHandler` + `UploadQueue` each own an independent `SemaphoreSlim(20,20)`). `aws_sdk_s3::Client` is `Clone + Send + Sync`; every C-ABI method takes `*const DS3S3Client` (shared `&`). **Do NOT add a C#-side mutex around S3 calls** — it would serialize and kill throughput. The only mutation point is dispose, which `Interlocked.Exchange` makes single-shot.

### `DriveS3SessionAccess.cs` (NEW) — per-drive sync adapter

**Analog:** the `IDS3SessionAccess` explicit implementation on `AuthenticationService` (`AuthenticationService.cs:212-237`). That impl routes all 6 ops through `EnsureSession()` (the session handle — THE bug). The new adapter wraps **one `DS3DriveS3Client`** and routes the same 6 ops through it. The seam interface (`IDS3SessionAccess.cs:15-34`) stays **unchanged** (do not widen it — its signatures carry no drive context).

**Shape to copy** (`AuthenticationService.cs:216-237`), swapping `EnsureSession()` → the injected `DS3DriveS3Client`:
```csharp
string IDS3SessionAccess.AccountId => CurrentAccount?.AccountId ?? string.Empty;

IReadOnlyList<DS3Object> IDS3SessionAccess.ListObjects(string bucket, string prefix, string delimiter, string? continuationToken) =>
    EnsureSession().ListObjects(bucket, prefix, delimiter, continuationToken);

DS3Object IDS3SessionAccess.DownloadObject(string bucket, string key, string filePath, DS3ProgressCallback? progress, CancellationHandle? cancel) =>

string IDS3SessionAccess.UploadObject(string bucket, string key, string filePath, DS3ProgressCallback? progress, CancellationHandle? cancel) =>
```

## Shared Patterns

### FFI panic guard
**Source:** `ffi_guard!` macro (`core/ds3-ffi/src/panic_guard.rs:23`), used by every export in `c_exports.rs`.
**Apply to:** `ds3_s3_client_new` (wraps the body; returns -2 on panic, sets `*out_error`). `ds3_s3_client_destroy` needs no guard (no panic surface, just `Box::from_raw` + drop).

### Optional-string + UTF-8 marshalling (Rust side)
**Source:** `ffi_str` (`c_exports.rs:35`), `ffi_opt_str` (`c_exports.rs:48`), `write_ffi_string` (`c_exports.rs:60`).
**Apply to:** `ds3_s3_client_new` — `ffi_str` for the 3 required strings, `ffi_opt_str` for `region`. No `write_ffi_string` (the mint returns a handle, not JSON).

### UTF-8 + native-buffer RAII (C# side, the `M` helpers)
**Source:** `DS3Session.M` nested class (`DS3Session.cs:388-421`): `Utf8`, `Len` (byte-count from us — T-17-05-01), `TakeString` (frees via `ds3_free_string`), `FreeString`, `WrapProgress`.
**Apply to:** `DS3DriveS3Client` (mint + every S3 method). Extract to a shared internal helper or copy verbatim.

### Error-code → typed exception
**Source:** `DS3ExceptionFactory.From(err)` (`DS3ExceptionFactory.cs:38-52`) — 1001-1008 → auth, 2001-2099 → `DS3S3Exception`, 3001-3099 → `DS3TransportException`, 9999 → panic.
**Apply to:** `DS3DriveS3Client` (mint + every S3 method, via the copied `Check`/`Parse<T>` helpers `DS3Session.cs:364-386`) and the wizard `MapErrorCopy`.

### Single-shot dispose guard
**Source:** `Interlocked.Exchange(ref _handle, IntPtr.Zero)` (`DS3Session.cs:340-347`).
**Apply to:** `DS3DriveS3Client.Dispose` (double-dispose is a no-op; does NOT protect a concurrent in-flight call — ordering in `StopActiveAsync` does, Pitfall 4).

### Handle short-circuit
**Source:** `EnsureHandle()` throwing `DS3AuthenticationException(LoggedOut, 1005)` (`DS3Session.cs:351-360`).
**Apply to:** `DS3DriveS3Client` (every S3 method calls `EnsureHandle()` first).

### macOS behavioral parity (cache + rebuild + dispose-last)
