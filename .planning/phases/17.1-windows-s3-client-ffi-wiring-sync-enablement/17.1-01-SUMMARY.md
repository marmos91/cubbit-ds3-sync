## Decisions Made
- `ds3_s3_client_new` performs no `runtime().block_on` because `DS3S3Client::new` is synchronous (only builds the aws-sdk-s3 client config; no network I/O). The only fallible operation is the UTF-8 decode of the input buffers — diverges from the `ds3_authenticate` analog precisely here.
- `region` is marshalled via `ffi_opt_str` (null ptr OR `len == 0` ⇒ `None` ⇒ Rust defaults to `us-east-1`), matching macOS which supplies no region. No custom C#-side null sentinel.
- The integration test resolves the plan-02 `DS3DriveS3Client` facade by `Assembly.GetType` and no-ops when absent, so the Wave 0 file compiles against today's assembly (the facade lands in plan 17.1-02). This satisfies the Nyquist contract: the verification loop precedes the consumer.
- D-06 tests BOTH error branches because a bad access key surfaces as DS3Error code 3003 ⇒ `DS3TransportException`, NOT `DS3S3Exception` (verified A1 against `core/ds3-models/src/error.rs`); `InvalidAccessKeyId` does not land in the 2001-2099 S3 range.

## Issues Encountered
- **Local DLL build blocked (expected, STATE 17-02):** `cargo check -p ds3-ffi` and the `build-dll-windows.ps1` rebuild both fail at the `ring` / `aws-lc-rs` build scripts ("failed to find tool clang") because the dev box lacks the MSVC C++ / clang toolchain. This halts before ds3-ffi's own compilation is reached, so the Rust source could not be type-checked locally. Mitigation per the accepted Phase-17 workflow: the export source is verified structurally (copies the proven `ds3_authenticate` mint shape and `ds3_session_destroy` drop shape verbatim, swapping the type and removing `block_on`), the export-count grep returns 2, and the actual DLL build/link runs in `windows-build.yml` on `windows-latest`.
- **xUnit 2.9.0 lacks `Assert.Skip` / `Assert.SkipUnless` / `exactMatch:`:** those APIs are xUnit 2.9.3+/v3. The managed-only lifecycle tests therefore no-op (early `return`, pass) when the plan-02 facade is absent, and the live tests use the existing `[RequiresCredentials]` skip-attribute. All assertions use xUnit-2.9.0-available APIs (`Assert.IsAssignableFrom`, `Assert.ThrowsAny`, `Assert.False`).
