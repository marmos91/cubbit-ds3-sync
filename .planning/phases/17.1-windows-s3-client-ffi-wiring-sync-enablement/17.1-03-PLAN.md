## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Wizard/sync (C#) → Rust C-ABI | S3 ops cross with the per-drive DS3DriveS3Client handle; the API-key secret is re-hydrated transiently from Credential Manager |
| CredentialStore (OS-sealed) → S3 client build | The secret crosses into DS3DriveS3Client.Create as a UTF-8 buffer and is not retained C#-side |
| Drive teardown → in-flight sync op | Dispose must be ordered after the engine stops to avoid use-after-free |
