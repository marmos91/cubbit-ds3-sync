<objective>
Wire the launch-time silent rollout (THUMB-23, D-01, D-02, D-03):

1. **First-launch re-check** — On extension launch, iterate drives. For each drive, check whether `ThumbnailSettings` has ever been persisted (i.e., whether the JSON file exists in App Group container). If NOT (first v3.1 launch), call `inspectThumbnailPrefix(bucket:drivePrefix:s3Client:)` (Phase 11). If state is `.empty` or `.matchesOurs`, persist `ThumbnailSettings(enabled: true)` via `SharedData.saveThumbnailSettings`. If `.conflicting`, persist `ThumbnailSettings(enabled: false)`. Either way, write SOMETHING so subsequent launches don't re-check.

2. **Subsequent launches: read-only** — If `ThumbnailSettings` already exists for a drive, just read it (don't re-check inspectThumbnailPrefix). Per D-02, re-check only happens on drive-add (already done by Phase 11 wizard) or drive-remove (irrelevant). The launch hook is therefore a no-op after first run.

3. **Silent UX (D-03)** — No NSUserNotification, no toast, no log "first run!" banner, nothing user-facing. The only side effect is one S3 ListObjectsV2 per drive on first launch + one SharedData JSON write per drive.

4. **Background Task** — Rollout iteration runs in `Task.detached` to avoid blocking extension launch. Failures (e.g., S3 unreachable on first launch) are logged + swallowed; the rollout retries on next launch (the JSON file isn't written if inspectThumbnailPrefix throws).

Purpose: This is the "switch turning on" for thumbnails on existing drives. Without this plan, no drive ever gets enabled=true automatically; without the once-per-drive cache, every cold-start pays N×ListObjectsV2.
Output: New helper file + lifecycle hook + test file.
</objective>

    **Step A — Create `DS3DriveProvider/ThumbnailRollout.swift`:**

    ```swift
    import Foundation
    import DS3Lib

    /// Once-per-drive silent rollout: on first v3.1 launch, runs collision re-check
    /// and persists ThumbnailSettings.enabled. Subsequent launches read the persisted
    /// flag without re-checking. Per Phase 13 D-01, D-02, D-03.
    struct ThumbnailRollout {
        let s3Client: any DS3S3ClientProtocol
        let sharedData: SharedData
        let logger: Logger

        /// For a single drive, run the rollout if it has never been persisted.
        /// Idempotent — safe to call on every launch.
        func runIfNeeded(forDrive drive: DS3Drive) async {
            // D-02: skip if already persisted
            if sharedData.hasThumbnailSettings(forDrive: drive.id) {
                return
            }

            do {
                let bucket = drive.syncAnchor.bucket.name
                let prefix = drive.syncAnchor.prefix
                let state = try await s3Client.inspectThumbnailPrefix(bucket: bucket, drivePrefix: prefix)
                let enabled: Bool
                switch state {
                case .empty, .matchesOurs: enabled = true
                case .conflicting: enabled = false
                }
                let settings = ThumbnailSettings(enabled: enabled)
                try sharedData.saveThumbnailSettings(forDrive: drive.id, settings: settings)
                logger.info("ThumbnailRollout: drive \(drive.id.uuidString, privacy: .public) settings persisted enabled=\(enabled)")
            } catch {
                // D-03: silent — log + swallow; will retry on next launch (no settings file written).
                logger.warning("ThumbnailRollout: drive \(drive.id.uuidString, privacy: .public) skipped due to error: \(error.localizedDescription, privacy: .public)")
            }
        }
    }
    ```
