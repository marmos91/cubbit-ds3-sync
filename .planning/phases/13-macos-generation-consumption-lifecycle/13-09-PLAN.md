<objective>
Wire the BFS pass-tail hooks (THUMB-15, 21, 23 + THUMB-19):

1. **Coordinator hook (D-16, D-17)** — `BreadthFirstIndexer` lazy-initializes a `ThumbnailBackfillCoordinator` per drive. After each successful `runOneBFSPass`, if `thumbnailSettings.enabled == true && drive.status != .paused`, invoke `coordinator.runBatch(maxItems: DefaultSettings.Thumbnail.backfillBatchSize)` via a fire-and-forget Task. Per D-17, this does not extend the BFS pass duration. The Task handle is stored on the indexer so a subsequent pause-flip can call `.cancel()` on it (Plan 13-05 coordinator handles cancellation propagation cleanly).

2. **Orphan sweep (D-25, D-26, D-27)** — New type `OrphanSweeper` (extension-side per D-25). Its method `sweep(bucket:drivePrefix:enumeratedKeys:)` lists `<drivePrefix>.thumbnails/` (max 1000), maps each thumbnail key back to the implied original via `S3PathUtils.originalKey(fromThumbnailKey:drivePrefix:)`, and deletes any whose implied original is NOT in `enumeratedKeys`. Capped at `DefaultSettings.Thumbnail.maxOrphanDeletesPerPass` (50) per pass. Sweep is invoked AFTER the coordinator hook in the same BFS pass tail; gated by `thumbnailSettings.enabled`.

3. **Pause-aware cancellation** — When the drive flips to paused (existing pause flow), the indexer should call `.cancel()` on the in-flight backfill Task. This is the BFS-side counterpart to Plan 13-05's coordinator-side Task.checkCancellation handling.

Purpose: This plan turns the silent payload of Phases 11/12 into an active backfill engine. Combined with Plan 13-07's upload hook, this is the difference between "thumbnails appear for new uploads" (Plan 13-07) and "thumbnails progressively populate for existing content" (Plan 13-09 BFS hook + sweep).
Output: New OrphanSweeper file + BFS indexer wiring + 2 test files.

    ```swift
    import Foundation
    import DS3Lib

    /// Computes orphan thumbnail keys (no corresponding original) and bulk-deletes them.
    /// Per Phase 13 D-25, D-26, D-27. Uses the BFS-enumerated original key set as the source of truth.
    /// Sweeping is gated externally by the caller via ThumbnailSettings.enabled (D-27).
    struct OrphanSweeper {
        let s3Client: any DS3S3ClientProtocol
        let logger: Logger

        /// Lists `<drivePrefix>.thumbnails/`, computes which thumbnails have no surviving original
        /// in `enumeratedKeys`, and deletes them. Returns the count of deletes issued (for logging).
        /// Cap is `DefaultSettings.Thumbnail.maxOrphanDeletesPerPass` (50).
        func sweep(
            bucket: String,
            drivePrefix: String,
            enumeratedKeys: Set<String>
        ) async -> Int {
            let prefix = (drivePrefix.isEmpty ? "" : (drivePrefix.hasSuffix("/") ? drivePrefix : drivePrefix + "/")) + DefaultSettings.S3.thumbnailsPrefix
            let cap = DefaultSettings.Thumbnail.maxOrphanDeletesPerPass

            do {
                // List up to 1000 thumbnail keys for this drive.
                let allThumbKeys = try await s3Client.listAllKeys(bucket: bucket, prefix: prefix, maxKeys: 1000)
                // ^ NOTE: confirm this method exists on DS3S3ClientProtocol; if not, use whatever Phase 11 listObjectsV2 wrapper exists in S3Lib.swift. Read S3Lib.swift first.

                var deleted = 0
                for thumbKey in allThumbKeys {
                    if deleted >= cap { break }
                    if thumbKey.hasSuffix("/") { continue }  // skip folder markers
                    guard let originalKey = S3PathUtils.originalKey(fromThumbnailKey: thumbKey, drivePrefix: drivePrefix) else {
                        // Unparseable thumb key — skip rather than delete (defensive).
                        continue
                    }
                    if enumeratedKeys.contains(originalKey) { continue }
                    do {
                        try await s3Client.deleteThumbnail(bucket: bucket, key: thumbKey)
                        deleted += 1
                    } catch {
                        logger.warning("Orphan sweep delete failed for \(thumbKey, privacy: .public): \(error.localizedDescription, privacy: .public)")
                    }
                }
                if deleted > 0 {
                    logger.info("Orphan sweep deleted \(deleted) orphan thumbnails (cap=\(cap))")
                }
                return deleted
            } catch {
                logger.warning("Orphan sweep listing failed: \(error.localizedDescription, privacy: .public)")
                return 0
            }
        }
    }
    ```
